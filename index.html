Windows 11 高速化セッティング

ONにしたい項目を選ぶと、実行用のPowerShellスクリプトが自動生成されます。

ブラウザからWindowsの設定を直接変更することはできないため、スクリプトを生成してお使いのPCで実行する方式です。実行前に内容を確認し、復元ポイントの作成をおすすめします。

生成されたスクリプト 










使い方


    

  1. 「コピー」を押し、メモ帳に貼り付けて speedup.ps1 として保存します（文字コードはUTF-8）。
    2. 

  2. 管理者項目を含む場合は、スタートを右クリック →「ターミナル (管理者)」を開きます。
    3. 

  3. Set-ExecutionPolicy -Scope Process Bypass を実行してから .\speedup.ps1 を実行します。
    4. 

  4. 完了後、PCを再起動すると設定が確実に反映されます。
